# Lahari Nemani — Portfolio Website

A responsive, single-page portfolio website ready for GitHub Pages.

## Personalize before publishing
1. Add your portrait photo to this folder and name it `profile.jpg`.
2. In `index.html`, replace `YOUR_EMAIL@example.com` with your email address.
3. Replace the LinkedIn URL with your actual profile.
4. Check the project descriptions and technology tags. In particular, update the Smart Waste Segregation hardware/software tags so they exactly match your final project report.
5. Add exact certificate names and credential links if you have them.

## Publish with GitHub Pages
1. Create a **public** repository named `lahari0306.github.io`.
2. Upload both `index.html` and `profile.jpg` (and optionally this README) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. After GitHub finishes deploying, visit `https://lahari0306.github.io`.

The site uses Google Fonts; if the visitor is offline, it falls back to local sans-serif fonts.
